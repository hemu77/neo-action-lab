Prototype boundary

Local, synthetic data only. The Planner and Reader are fixture code. Egress attacks are typed request proposals, not intercepted live traffic. This web dialog cannot provide browser-chrome isolation.

Production design

The accompanying documents specify separate Grok sessions, signed contracts, reviewed site adapters, full network mediation, Norton reputation integration, and trusted browser confirmation. Those integrations require independent validation.

Accepted risk

Wrong-but-allowed choices, dishonest authorized merchants, and confirmation fatigue remain explicit risks. A good-looking trace does not prove security on the open web.
